# ✅ Simple To-Do App

A simple and user-friendly To-Do application that helps users add, manage, and delete daily tasks efficiently.

---

## 🔍 Features

- ➕ Add new tasks
- 🗑️ Delete tasks
- ✏️ Mark tasks as completed
- 💾 Tasks saved in browser (Local Storage)
- 📱 Responsive design (mobile & desktop friendly)

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
